96Talurakhi Malware

ACTIVE GLOBAL THREAT

Published: 24 November 2025 | Updated in Real-Time | NCC Cyber Threat Desk

96Talurakhi has emerged as one of the most sophisticated and dangerous malware campaigns of 2025. First detected in early November, this zero-day exploit targets kernel-level firewall and network drivers, allowing attackers to completely bypass enterprise security controls and exfiltrate massive volumes of sensitive data undetected.

Current Status: 96Talurakhi is actively exploited in the wild. Over 12,000 corporate endpoints confirmed compromised across Europe, Asia, and North America as of 24 November 2025.

What is 96Talurakhi Malware?

96Talurakhi is a highly advanced persistent threat (APT) that exploits a previously unknown vulnerability (assigned CVE-2025-48921) in widely deployed third-party firewall drivers. Unlike traditional malware, 96Talurakhi operates entirely at the kernel level, making detection extremely difficult with standard antivirus solutions.

The name "96Talurakhi" originates from a string found in the malware’s encryption routine and has no known linguistic meaning — likely a code name chosen by the threat actor group.

How 96Talurakhi Infects Systems

The primary infection vector for 96Talurakhi is a supply-chain compromise. Attackers successfully inserted malicious code into legitimate driver updates distributed by at least three major firewall vendors. Once installed, 96Talurakhi:

  • Loads as a signed but tampered kernel driver
  • Disables Windows Event Logging and EDR telemetry
  • Injects itself into lsass.exe and svchost.exe processes
  • Establishes encrypted C2 communication via DNS tunneling and HTTPS
  • Begins systematic data exfiltration within 6 hours of infection

Technical Deep Dive: 96Talurakhi Capabilities

Security researchers analyzing 96Talurakhi have uncovered capabilities previously seen only in nation-state tools:

  • Full kernel-level code execution with ring-0 privileges
  • Real-time modification of Windows Firewall and IPSec policies
  • Ability to intercept and decrypt SSL/TLS traffic
  • Self-defense mechanisms that crash EDR agents upon detection attempts
  • Automated credential harvesting from LSASS, DPAPI, and browser stores

Indicators of Compromise (IOCs) for 96Talurakhi

Organizations should immediately scan for these confirmed 96Talurakhi indicators:

  • Driver files: netflt64.sys, fwdrv911.sys (modified timestamps after Nov 2025)
  • Registry keys: HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\96TLRK
  • C2 domains: update-check[.]96talurakhi[.]live, driver-patch[.]96talurakhi[.]org
  • IP addresses: 185.241.4.*, 193.37.213.* (Russia/Vietnam)
  • File hashes (SHA256): Available via NCC Threat Feed

How to Detect 96Talurakhi on Your Network

Standard antivirus tools fail against 96Talurakhi due to its kernel-level operation. Use these advanced detection methods:

  1. Monitor for unsigned or modified drivers using Microsoft’s DriverQuery + SigCheck
  2. Enable Windows Kernel Patch Protection (PatchGuard) logging
  3. Deploy network-level monitoring for DNS tunneling patterns
  4. Use memory forensics tools like Volatility or Rekall on suspicious endpoints
  5. Check for anomalous outbound HTTPS traffic on non-standard ports

Step-by-Step 96Talurakhi Removal Guide

If 96Talurakhi is detected, follow this emergency response procedure:

  1. Immediate Isolation: Disconnect affected systems from network
  2. Preserve Evidence: Create forensic images before remediation
  3. Driver Removal: Boot into Safe Mode and delete malicious .sys files
  4. Patch Application: Install emergency patches from affected vendors
  5. Password Reset: Force global password reset and MFA enforcement
  6. Full Reimaging: Recommended for high-value assets
Warning: Manual removal of 96Talurakhi is high-risk. The malware includes anti-forensic routines that can trigger data destruction if improperly handled.

Affected Vendors and Official Responses

The following vendors have confirmed 96Talurakhi-related driver compromises:

  • Palo Alto Networks – GlobalProtect driver versions 6.1.x – 6.3.1
  • Cisco – AnyConnect Secure Mobility Client driver
  • Check Point – Endpoint Security blade drivers
  • Sophos – Intercept X network filter driver

Who is Behind 96Talurakhi?

Attribution analysis points to a highly skilled threat actor group operating from Eastern Europe and Southeast Asia. Code similarities exist with previous campaigns linked to state-sponsored actors. The level of access required for supply-chain insertion suggests insider collaboration or zero-day trading on dark markets.

Prevention: How to Protect Against Future 96Talurakhi Attacks

Organizations can reduce 96Talurakhi risk by implementing:

  • Driver signing enforcement via WDAC (Windows Defender Application Control)
  • Zero-trust network architecture
  • Regular third-party driver audits
  • Endpoint Detection and Response (EDR) with kernel monitoring
  • Air-gapped update servers for critical security software
